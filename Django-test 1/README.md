# Конные и активные туры

Учебный Django-проект для каталога конных, пеших и других активных туров.
Публичный каталог доступен по адресу `/tours/`, административная панель —
`/admin/`.

## Запуск

```powershell
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Главная страница блога доступна по адресу `/`, страница статьи — `/blogs/<id>/`.

## Туры и связи

- `RiderProfile` связан с пользователем один к одному.
- `Tour` и `Category` связаны многие ко многим: один тур может иметь категории
	«Конный» и «Пеший» одновременно.
- `Booking` связан с пользователем и туром отношениями многие к одному. База
	данных запрещает одному клиенту бронировать разные туры на одинаковые дату и
	время.
- `Review` принадлежит брони, клиенту и туру. Оставить отзыв можно только по
	завершенной поездке; на одну бронь разрешен один отзыв.

Посетитель регистрируется на `/tours/register/`, входит через `/accounts/login/`
и отправляет бронирование со страницы тура. Создавать туры, категории и
отмечать поездки завершенными можно через Django Admin.

## Дополнительные примеры

Приложение `crud` — учебный пример полного CRUD-цикла для модели `Item`:

- список и просмотр записи;
- создание и редактирование через `ModelForm`;
- удаление с подтверждением.

Страницы доступны с префиксом `/crud/`. Это приложение можно использовать как
основу для следующих заданий: создайте приложение командой
`python manage.py startapp имя_приложения`, скопируйте структуру `crud`,
замените модель `Item` и обновите регистрацию приложения в `INSTALLED_APPS`
и `blog_project/urls.py`.

После изменения моделей создайте и примените миграции:

```powershell
python manage.py makemigrations
python manage.py migrate
```

## Тесты

```powershell
python manage.py test
```

При каждом запуске `python manage.py test` Django test runner автоматически
создает или обновляет `docs/test_documentation.md` с перечнем тестов и
результатами. Описание предметной области и связей моделей находится в
`docs/tour_startup.md`.
