# Стартап «Конный тур»

## Предметная область

Сервис публикует туры разных типов: конные, пешие, мототуры и другие. Клиент
создает аккаунт, выбирает тур и бронирует время. После завершенной поездки он
может оставить отзыв.

## Связи моделей

| Связь | Реализация | Назначение |
| --- | --- | --- |
| Один к одному | `User` — `RiderProfile` | Один профиль с телефоном на аккаунт клиента |
| Один ко многим | `User` — `Booking` | У клиента может быть несколько броней |
| Один ко многим | `Tour` — `Booking` | На тур могут записаться разные клиенты |
| Один ко многим | `Booking` — `Review` | Для завершенной брони хранится один отзыв |
| Многие ко многим | `Tour` — `Category` | У тура может быть несколько категорий и наоборот |

## Правила бронирования и отзывов

- Ограничение `one_booking_per_rider_datetime` запрещает клиенту иметь более
  одной брони на одинаковые дату и время, даже если выбраны разные туры.
- Проверка действует и в форме, и в ограничении базы данных.
- Отзыв можно отправить только для завершенной брони текущего пользователя.
- Повторный отзыв по той же брони запрещен связью один к одному.
